# 全员 Vibe Coding · 展示系统

一个纯静态单页网站，用于宣讲与展示 **Vibe Coding（全员氛围编程）** 的理念、工作流与落地方法。

## 包含内容

- **理念介绍**：什么是 Vibe Coding，三个核心特征
- **四步工作流**：描述意图 → 生成预览 → 审查验证 → 迭代沉淀
- **互动演示**：内置「提示词生成器」，现场演示如何把想法变成结构化提示词
- **三阶段落地路线**：试点尝鲜 → 推广复制 → 组织能力
- **风险治理清单**：6 项可勾选的自检表（带进度条）
- **FAQ**：常见疑虑解答

## 使用方式

无需构建、无任何依赖，直接用浏览器打开 `index.html` 即可，也可部署到 GitHub Pages。

## 技术栈

单个 `index.html`：原生 HTML + CSS + JavaScript，零依赖，方便二次编辑。
